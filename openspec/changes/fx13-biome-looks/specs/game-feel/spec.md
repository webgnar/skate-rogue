# Spec Delta

## ADDED Requirements

### Requirement: Biome looks
Each biome in the GDD SHALL have a colour grade over the time of day and an ambient drift, applied when gameplay
sets the biome, in one extra draw call.

#### Scenario: Atlantis
- **WHEN** a floor is set in Atlantis
- **THEN** the sky turns teal, fog closes in, and bubbles rise through the view
