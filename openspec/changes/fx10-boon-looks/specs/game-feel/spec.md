# Spec Delta

## ADDED Requirements

### Requirement: Boon and board mod looks
Each held boon SHALL show a look in its card colour when it acts, and each board mod effect SHALL show a look when
it fires, using the shared particle pool only.

#### Scenario: Big Pop
- **WHEN** the skater ollies holding Big Pop
- **THEN** a POP-yellow ring kicks out flat under the board

#### Scenario: Cash Burst fires
- **WHEN** a Cash Burst mod fires
- **THEN** green confetti pops up from the skater
