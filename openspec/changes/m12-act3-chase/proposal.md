# Proposal

## Why

Act 3 reused the act 1 roadblock. The GDD gives act 3 a set piece per district (the flood, the chariot race, the
guards). Overnight 2026-10-24 a decision card offered zack three options; this builds the recommended one.

## What Changes

- Act 3's escape is a chase. The district's chaser (a wave in Atlantis, a chariot in Greece, guards in the museum)
  runs a few tiles behind. Each slam lets it close in, clean skating slowly opens the gap, and if it reaches you
  you're caught.
- Callouts per district, the HUD warning when it's close, and placeholder looks built from primitives.

## Capabilities

### New Capabilities

- `act3-chase`: the act 3 escape chase.
